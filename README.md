# Sistema de Gestión Académica

Proyecto de Programación I de la Universidad de Manizales. Se desarrollará en Python y evolucionará durante las actividades colaborativas 1 y 2.

## Estado actual

Estructura inicial con arquitectura Modelo–Vista–Controlador (MVC). Las funcionalidades académicas y la interfaz están pendientes de implementación.

## Estructura

```text
sistema-gestion-academica/
├── main.py
├── models/
├── views/
├── controllers/
├── docs/
├── README.md
└── requirements.txt
```

- `models/`: entidades académicas y reglas del sistema.
- `views/`: presentación e interfaz de usuario.
- `controllers/`: coordinación entre las vistas y los modelos.
- `docs/`: propuesta inicial y documentación de diseño.
- `main.py`: punto de entrada de la aplicación.
- `requirements.txt`: dependencias externas, pendientes de definir.

## Ejecución

Desde la carpeta del proyecto, con Python 3:

```bash
python main.py
```

Por ahora el archivo principal finaliza sin mostrar información, ya que solo contiene la estructura de inicio.
